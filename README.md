## 這個系列的設計

- **生活問題先行**：每集開場先問一個日常問題，例如「披薩加大為什麼划算」「團購出價比成本低要不要接」，再帶出數學觀念。
- **數字由程式計算**：畫面上的面積、利潤、成本都由程式算出，案例中的價格與銷量是教學假設，畫面標示「假設」。
- **接續上一集**：每集開頭接上一集的問題，結尾預告下一集，說明欄附「先看／接著看」。
